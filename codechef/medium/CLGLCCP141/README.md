## Problem

### Comparing Shoe Sizes

In this example, we demonstrate how the Less Than (<) operator can be used to compare the sizes of two shoes. The program checks if one shoe size is less than the other, and displays the result.

 **When executed the code will show:** 

```
Is shoeSize1 less than shoeSize2? 1
Is shoeSize1 less than shoeSize2? 0

```

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A

```c_cpp
#include <stdio.h>

int main() {
   
    // Compare using the less than operator (<)
    printf("Is shoeSize1 less than shoeSize2? 1\n");  // Expected output: 1 (true)

    // Change shoeSize1 to a larger size
   
    // Compare again using the less than operator
    printf("Is shoeSize1 less than shoeSize2? 0\n");  // Expected output: 0 (false)

    return 0;
}
```
