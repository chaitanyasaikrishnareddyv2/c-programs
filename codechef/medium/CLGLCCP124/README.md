## Problem

### Worked Example - Calculating Exam Attempts

This example demonstrates how increment and decrement operators affect exam attempt calculations, with the result depending on whether they're used in pre or post form.

 **When executed, the code will show:** 

```
Total attempts allowed: 5
Remaining attempts after reduction: 3
Final bonusAttempts: 3
Final maxAttempts: 2

```

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-30T23:51:01.166Z  

```c_cpp
#include <stdio.h>

int main() {
 
    printf("Total attempts allowed: 5\n");  // 3 + 2 = 5

    
  
    printf("Remaining attempts after reduction: 3\n");  // 2 + 1 = 3

    // Final values of the variables
    printf("Final bonusAttempts: 3\n");  // 3
    printf("Final maxAttempts: 2\n");      // 2

    return 0;
}
```
