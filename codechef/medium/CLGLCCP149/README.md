## Problem

### Worked Example - Comparing Student Grades

In this example, we demonstrate how the Less Than or Equal To (<=) operator is used to compare the grades of two students. The program checks if the first student's grade is less than or equal to the second student's grade, and displays the result.

 **When executed, the code will show:** 

```
Is grade1 less than or equal to grade2? 1
Is grade1 less than or equal to grade2? 0

```

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-10-01T00:11:18.817Z  

```c_cpp
#include <stdio.h>

int main() {
    
    // Compare using the less than or equal to operator (<=)
    printf("Is grade1 less than or equal to grade2? 1\n");  

    // Change grade1 to a greater value
   // Now grade1 is greater than grade2

    // Compare again using the less than or equal to operator
    printf("Is grade1 less than or equal to grade2? 0\n");  

    return 0;
}
```
