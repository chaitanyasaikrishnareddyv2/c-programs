### BMI Calculator Using Assignment Operators

Write a program to calculate the Body Mass Index (BMI) of a person using their weight and height.

 **Given Data** : Weight = 72.0, Height = 1.75

 **Steps to Complete:** 

- Store weight and height in separate float variables.
- Square the height using multiplication assignment (*=).
- Use division assignment (/=) to calculate BMI as weight / (height * height).
- Store the result in the same weight variable (acting as bmi).
- Print the final BMI rounded to 2 decimal places.

 **Expected Output:** 

```
Calculated BMI: 23.51

```
