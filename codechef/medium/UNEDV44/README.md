### Declare Your Age

In this task, you will declare your age as an integer in Python. Start by choosing your current age (e.g., 25), and then store it in a variable named my_age. Afterward, you’ll verify that your variable is indeed an integer by printing its type.

 **Steps to Complete** 

- Choose your current age (for example, 25).
- Declare a variable named my_age and assign your age to it (e.g., my_age = 25).
- Use the type() function to determine the data type of my_age.
- Print the result to confirm that it is an integer.

Once you’ve written your code, run it to see if it shows <class 'int'> as the output. Then click “Submit” when you’re ready!
