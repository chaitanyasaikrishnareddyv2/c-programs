## Problem

### Worked Example - Assigning the Store Inventory

In this example, we demonstrate how `chained assignment` allows `multiple variables` to be assigned the `same initial stock quantity` in a single statement.

 **When executed, the code will show:** 

```
Store 1 Initial Stock: 500 units
Store 2 Initial Stock: 500 units
Store 3 Initial Stock: 500 units

```

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-30T23:37:05.733Z  

```c_cpp
#include <stdio.h>

int main() {
   
    printf("Store 1 Initial Stock: 500 units\n");  // Output: 500
    printf("Store 2 Initial Stock: 500 units\n");  // Output: 500
    printf("Store 3 Initial Stock: 500 units\n");  // Output: 500

    return 0; 
}
```
