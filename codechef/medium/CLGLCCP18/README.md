## Problem

### Print a message

In this example, we use `printf` to display two simple sentences introducing different pets:

`"This is my cat, Luna."` `"This is my dog, Max."`

 **When executed, the code will output:** 

```
This is my cat, Luna.This is my dog, Max.

```

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-26T22:16:46.841Z  

```c_cpp
#include <stdio.h>  // Include standard input/output library

int main() {
    // Print the name of a cat
    printf("This is my cat, Luna.");

    // Print the name of a dog
    printf("This is my dog, Max.");

    return 0;  // Indicate successful program termination
}
```
