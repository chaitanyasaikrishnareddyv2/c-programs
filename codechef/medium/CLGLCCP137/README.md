## Problem

### Comparing Temperatures with the Greater Than

In this example, we demonstrate how the Greater Than (>) operator can be used to compare temperatures. The program checks if one temperature (say, the current temperature) is greater than another (e.g., the freezing point of water).

 **When executed, the code will show:** 

```
Is the current temperature greater than the freezing point? 1
Is the current temperature greater than the freezing point? 0

```

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-10-01T00:02:20.022Z  

```c_cpp
#include <stdio.h>

int main() {
    
    // Compare if current temperature is greater than freezing point
    printf("Is the current temperature greater than the freezing point? 1\n");
    // Compare again if current temperature is greater than freezing point
    printf("Is the current temperature greater than the freezing point? 0\n");
    return 0;
}


```
