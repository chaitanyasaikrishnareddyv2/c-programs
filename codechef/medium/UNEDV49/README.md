## Problem

### The Game of Number Sum

You are running a game where kids pick balls labeled with both positive and negative numbers. Your goal is to calculate the total sum of the numbers on three selected balls.

 **Ball Values** 
• Ball 1: 20
• Ball 2: -3
• Ball 3: 5

 **Expected Output** 
When you add 20, -3, and 5, the sum should be:

```
22

```

After you write your code, run it to verify the total is correct. Then proceed to the next step!

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-21T17:11:31.161Z  

```py
# Assigning values to three variables representing balls
ball_1 = 20  # Value of the first ball
ball_2 = -3   # Value of the second ball
ball_3 = 5   # Value of the third ball

# Calculating the total sum of the values of all balls
total_sum = ball_1 + ball_2 + ball_3  # Summing the values of ball_1, ball_2, and ball_3

# Printing the total sum to the console
print(total_sum)  # Output: 22
```
