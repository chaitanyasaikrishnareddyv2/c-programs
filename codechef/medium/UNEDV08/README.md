## Problem

### Share Your Favorite Hobby

In this task, you are required to create a program that displays the given info:

- Name: "Alice"
- Favorite Color: "Blue"
- Favorite Hobby: "Reading"

Your program should output the following format:

```
My name is Alice.
My favorite color is Blue.
My favorite hobby is Reading.

```

## Solution

**Language:** Python  
**Runtime:** N/A
