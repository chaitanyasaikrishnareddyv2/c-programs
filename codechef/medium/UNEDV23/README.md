## Problem

### Combining Words Using sep and end Parameters

In this task, you are required to create a custom message that combines three words ("Python", "for", and "Beginners") using the `print()` function with both the `sep` and `end` parameters.

You should display the message in the following format:

 **Expected Output** 

```
Python for Beginners!

```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-21T17:06:18.657Z  

```py
# Printing a custom message using sep and end parameters

# The sep=" " ensures that the words are separated by spaces

# The end="!" adds an exclamation mark at the end instead of the default newline

print("Python", "for", "Beginners", sep=" ", end="!")
```
