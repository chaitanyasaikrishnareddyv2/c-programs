## Problem

### MCQ - Printing the Percent Symbol in C

Which of the following C code snippets correctly prints only the percent symbol `%`?

 **A.** 

```
printf("%%");

```

 **B.** 

```
printf("%");

```

 **C.** 

```
printf("%c", %);

```

 **D.** 

```
printf("% percent");

```
